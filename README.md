# EventHub Connect

Create a simple full-stack web application called EventHub – College Event Management Platform, where students can register/login, discover upcoming college events, search and filter events by category, view event details, register for events, see their registered events and receive notifications. Create a separate admin dashboard where the admin can create, edit and delete events, manage students and registrations, and view basic statistics such as total events and participants. Use Python Django, SQLite, HTML, CSS, JavaScript and Bootstrap. Make the interface very classy, modern and professional, similar to a premium event-booking website, with a beautiful landing page, attractive event cards with posters, dark navy/white background with elegant purple or blue accents, modern typography, rounded cards, subtle animations, clean icons, responsive design and a professional dashboard. Keep the functionality simple and beginner-friendly, avoid unnecessary complex features, and make the final project polished enough for a hackathon presentation.
